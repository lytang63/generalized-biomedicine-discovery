概述

医学发现同时面临三种开放世界挑战：长尾中的罕见疾病、被正常解剖包围的微小病灶，以及诊断家族内的未见亚型。GBD 为这些真实的生物医学迁移提供了首个统一基准。SCAN 通过三阶段认知进程解决共同的失效模式——主导已知模式抑制弱新颖性信号——在所有设定中工作，无需辅助损失或异常标签。

💡 核心洞察

主导的已知模式形成视觉流形，掩盖了微妙的新颖性

🔬 三种临床设定

统一协议，不同的临床挑战

所有三种设定共享相同的 GCD 协议——只有已知类别被标记，而未标记数据混合已知和新颖样本。变化的是划分的临床来源，以及 SCAN 必须保护或揭示的视觉证据。

📊

Setting I: 长尾罕见疾病发现

临床动机：标注集中于频繁的病症。长尾中的罕见疾病在临床上至关重要但观察稀少。

主导模式问题：频繁的头部类别模式主导嵌入空间，掩埋来自罕见尾部疾病的低频线索。

SCAN 策略：构建头部模式锚点，然后几何隔离尾部特定残差。

🔍

Setting II: 正常到异常发现

临床动机：临床医生相对于多样的正常基线检测病理。多个正常解剖变体被标记；异常发现必须在未标记数据中被发现。

主导模式问题：正常解剖占据大部分像素，使微小病灶在特征空间中表示不足。

SCAN 策略：抑制正常解剖流形，然后使用惊奇唤起的显著性放大局部异常残差。

🌳

Setting III: 分类体系内发现

临床动机：医学分类是分层的。新亚型作为已建立诊断家族内的细粒度同级出现。

主导模式问题：语义上相邻的同级共享大部分形态学上下文，使细粒度亚型差异难以隔离。

SCAN 策略：通过正交适应保留父级结构，同时注入亚型互补性证据。

⚙️ 方法细节

从洞察到实现：SCAN 流程

SCAN 是一个轻量级的即插即用层，插入在主干网络之后和未改变的 GCD 头之前。三个阶段反映专家诊断认知，同时保持完全可微分。

Stage I

预测性抑制

大脑抑制可预测的感觉内容，为意外信号释放容量。SCAN 从证据槽构建样本条件的主导锚点，并几何投影出可预测的成分。

ri = xi − (xi⊤u)u

残差位于正交补空间中，揭示主导模式无法解释的内容。

Stage II

惊奇唤起的显著性

残差幅度衡量图像条件失配。当主导锚点解释不佳时，令牌是令人惊讶的。SCAN 将残差能量转换为显著性权重，并重新聚合由惊奇加权的证据。

si = ‖ri‖2,   wi ∝ exp(si/τs)

图像内排名集中于连贯的、未预测的偏差，无需跨数据集校准。

Stage III

互补性适应

发现必须在不扭曲已知结构的情况下整合偏差。SCAN 从激发的证据构建新颖性向量，将其投影到与主导锚点正交的互补子空间，并通过非参数惊奇门注入。

c̃ = c + γ · LN(Δ⊥ + xpool⊥)

当 γ 较小时，恒等路径恢复原始表示，限制特征漂移。

临床影响与未来方向

GBD 的目标不是与文本监督的多模态模型竞争的排行榜。它针对上游临床概念形成：将未标记的档案组织成连贯的队列，专家可以在整合到指南和精选数据集之前对其进行验证、命名、合并或拆分。这很重要，因为新兴疾病和亚型通常在不同地点和时间缺乏一致的命名法，而临床医生需要队列级发现、代表性原型和相似病例列表，而不是一次性预测。

三设定基准和认知启发的设计为持续发现、领域迁移发现、开放世界识别以及类别清单随时间演变的其他任务提供了可重用的接口。
